# SHA256 vs MD5 Explained

Both SHA256 and MD5 are cryptographic hash functions.

## What is MD5?

MD5 produces a 128-bit hash.

It is fast but no longer considered secure for cryptographic use.

## What is SHA256?

SHA256 produces a 256-bit hash.

It is more secure and widely used in blockchain and modern systems.

## Key Differences

| Feature | MD5 | SHA256 |
|---------|------|--------|
| Output Size | 128-bit | 256-bit |
| Security | Weak | Strong |
| Speed | Faster | Slower |
