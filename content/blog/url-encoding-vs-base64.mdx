# URL Encoding vs Base64 Encoding

Although both modify text data, they serve different purposes.

## URL Encoding

Used to make URLs safe for transmission.

Example: hello world


Becomes: hello%20world


Try it here: [URL Encoder](/tools/tool/url-encoder)

---

## Base64 Encoding

Used to encode binary data into ASCII text.

Example: hello


Becomes: aGVsbG8=


Try it here: [Base64 Encoder](/tools/tool/base64-encoder)
