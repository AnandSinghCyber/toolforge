# What is MD5?

MD5 (Message Digest Algorithm 5) is a cryptographic hash function that produces a 128-bit hash value.

Example: hello


MD5 Output: 5d41402abc4b2a76b9719d911017c592


## Is MD5 Secure?

No. MD5 is vulnerable to collision attacks and should not be used for secure systems.

## When Is MD5 Still Used?

- File integrity checks
- Legacy systems
- Non-security contexts
