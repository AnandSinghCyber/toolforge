# What is URL Encoding?

URL encoding (also called percent-encoding) converts special characters into a format that can be safely transmitted over the internet.

## Why is URL Encoding Needed?

URLs can only contain certain characters. Spaces and special symbols must be encoded.

Example: anand singh

Becomes: anand%20singh


## Common Encoded Characters

| Character | Encoded |
|-----------|---------|
| Space     | %20     |
| @         | %40     |
| &         | %26     |
| =         | %3D     |
