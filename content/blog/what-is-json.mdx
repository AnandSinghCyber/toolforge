# What is JSON?

JSON (JavaScript Object Notation) is a lightweight data format used for data exchange.

## Why is JSON popular?

- Lightweight
- Human-readable
- Easy to parse
- Supported everywhere

## Example JSON

```json
{
  "name": "ToolForge",
  "type": "Startup"
}
```
