# How SHA256 Hashing Works

SHA256 is part of the SHA-2 family of hashing algorithms.

## Step 1 — Input Message

The input is converted into binary format.

## Step 2 — Padding

The message is padded to a specific length.

## Step 3 — Compression Function

The algorithm processes data in blocks and mixes bits through multiple rounds.

## Final Output

The final result is a 64-character hexadecimal string.

Example: 2cf24dba5fb0a30e26e83b2ac5b9e29e...
